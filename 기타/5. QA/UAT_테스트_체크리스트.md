# UAT 테스트 프롬프트 — 마을 사보타주 추리 게임

작성일: 2026-08-09

## 0. 사전 준비

```
[ ] Docker Desktop 실행 확인 (docker info)
[ ] docker compose up -d (MySQL 컨테이너, localhost:3307)
[ ] backend ./gradlew bootRun (8080) → GET /health 200 확인
[ ] llm-proxy ./gradlew bootRun (8081) → GET /health 200 확인
[ ] frontend npm run dev (5173) 접속 확인
[ ] 신규 테스트 계정 1~2개 준비 (예: uat_tester01)
```

## TC-01. 회원가입 / 로그인 / 인증

| 단계 | 조작 | 기대 결과 |
|---|---|---|
| 1 | 신규 아이디로 회원가입 | 성공, 자동/수동 로그인 진행 |
| 2 | 동일 아이디로 재가입 시도 | 중복 에러(409) 안내 |
| 3 | 틀린 비밀번호로 로그인 | 실패 안내(401), 화면 멈춤 없음 |
| 4 | 정상 로그인 | 오프닝 화면으로 진입 |
| 5 | 로그아웃 후 이전 화면 접근 | 로그인 화면으로 유도되는지 (☆ 토큰 만료/401 전역 처리 미구현 이슈 — 로그인 화면으로 안 튕기고 멈출 수 있음, 재현되면 기록) |

## TC-02. 오프닝 컷씬

```
[ ] 캐릭터 생성 직후 오프닝 컷씬 1회만 노출되는지
[ ] 이미지 자체 캡션과 별도 텍스트가 겹쳐 보이지 않는지 (과거 수정된 버그 — 회귀 확인)
[ ] 성별 선택이 이후 맵 캐릭터 스프라이트에 정확히 반영되는지
```

## TC-03. 마을 이동 / 캐릭터 애니메이션

```
[ ] WASD로 이동 시 걷기 애니메이션이 실제로 재생되는지 (프레임이 바뀌는지)
[ ] 정지 시 정지 이미지로 자연스럽게 복귀 (걷기/정지 화풍 불일치 없는지)
[ ] 같은 방향으로 "이동→정지→같은 방향 재이동" 시에도 애니메이션이 다시 재생되는지 (과거 회귀 버그 지점)
[ ] 이동 중 스태미나가 실제로 감소하는지, 0이 되면 이동이 멈추는지
[ ] 타이틀 화면은 정적 배경 + BGM 자동재생(또는 최초 클릭/키입력 후 재생)인지
```

## TC-04. NPC 대화

```
[ ] NPC 클릭 시 대화창 오픈, 초상화/이름 표시
[ ] 같은 NPC와 하루 3회 대화 후 4번째 시도 시 차단 메시지("오늘 더 대화할 수 없습니다")
[ ] 대화창을 닫았다가 다시 열어도 카운트가 0으로 리셋되지 않고 서버 값(N/3) 그대로 유지되는지 (★ 과거 심각 버그 회귀 확인 필수)
[ ] 밤을 넘기면(day/advance) 새 날에는 카운트가 0/3으로 리셋되는지
```

## TC-05. 농사 시스템 (스타듀식)

```
[ ] 농산물 상점에서 씨앗 구매 → 골드 차감 확인(HUD/상점 헤더 동기화)
[ ] 인벤토리에 "○○ 씨앗" 아이템으로 들어오는지
[ ] 빈 밭 타일 클릭 → 씨앗 선택 팝업 → 심기 성공, 밭에 성장 1단계 텍스처 표시
[ ] 골드 부족 상태에서 씨앗 구매 시도 → 차단(409) 메시지
[ ] 덜 자란 작물 타일 클릭 → "아직 자라는 중입니다" 안내, 수확 안 됨
[ ] readyDay 도달 후 타일 클릭 → 수확 성공, 인벤토리 반영
[ ] 이미 수확한 타일 재수확 시도 → 차단
```

## TC-06. 채집 시스템

```
[ ] 나무/덤불 클릭 시 오늘 채집 가능한 종만 활성(밝게), 불가능한 종은 흐리게 표시
[ ] 오늘 가능한 과일 채집 성공 → 스태미나 소모 + 인벤토리 반영
[ ] 오늘 불가능한 과일 클릭 → "오늘은 여기서 딸 수 있는 게 없습니다" 안내
```

## TC-07. 상점 (농산물 상점 / 아이템 상점 분리)

```
[ ] 농산물 상점 건물 클릭 → 헤더 "농산물 상점", 씨앗 구매 탭 + 판매 탭 표시
[ ] 아이템 상점 건물 클릭 → 헤더 "아이템 상점", 구매만(판매 탭 없음)
[ ] 판매 탭에서 보유 작물/과일 판매 → 골드 증가가 HUD와 상점 헤더 양쪽에 즉시 반영
[ ] 영구 장비 중복 구매 시도 → 차단(409)
[ ] 존재하지 않는 아이템/작물 ID로 API 직접 호출(가능하면) → 400 응답
```

## TC-08. 사보타주 & 목격/소문 시스템

```
[ ] 사보타주가 발생한 밤 다음날, 해당 장소(수박밭/양계장 등) 맵 자산이 실제로 파손 이미지로 바뀌는지
[ ] 같은 장소가 이틀 연속으로 반복 피해를 입지 않는지 (그 이상 텀은 반복될 수 있음 — 정상)
[ ] 본인이 운영/근무하는 상점이 털렸을 때 본인도 인지 가능한지 (목격자 후보에 포함되는지)
[ ] 목격자로 추정되는 NPC에게 "밤에 이상한 일 없었어?" 류 질문 → 목격 관련 애매한 반응이 나오는지
[ ] 목격한 NPC → 다른 NPC에게 며칠 내로 소문이 전파되어(2차 목격) 그 NPC와도 대화 시 반응이 나오는지
```

## TC-09. 단서 습득

```
[ ] 사보타주 발생 장소 클릭 시 단서 텍스트 획득
[ ] 인벤토리(호감도 탭 포함)에서 단서/NPC 나이 등 참고 정보 확인 가능한지
[ ] 단서 내용이 실제 범인 특징과 모순되지 않는지 (지나치게 애매해서 무의미하지 않은지)
```

## TC-10. 고발 & 엔딩

```
[ ] 6일차 이전 고발 시도 → 차단(고발 가능일 아님)
[ ] 7~9일차에 정답 NPC 고발 → SUCCESS, 범인 동기 공개 이미지(npc별) 정상 노출
[ ] 정답 고발 시 "엔딩을 준비하는 중..." 로딩 화면이 먼저 뜨고, 결과 온 뒤에만 성공/실패 배지가 뜨는지 (★ 배드엔딩이 먼저 잘못 노출되는 과거 버그 회귀 확인)
[ ] 오답 고발 → 반응 텍스트 정상, 9일차까지는 다음날로 자동 진행
[ ] 9일차까지 오답만 반복 → BAD_ENDING, 고정 배드엔딩 컷씬(범인 무관 동일) 노출
[ ] 해피엔딩 시 마을 평화 컷씬(2번째 이미지)까지 정상 노출
```

## TC-11. 예외/경계 케이스

```
[ ] 다른 계정의 sessionId로 API 접근 시도 → 403 (IDOR 방지)
[ ] 만료/위조 토큰으로 요청 → 401
[ ] 세션 종료(GAME_OVER 등) 후 농장/상점/단서 액션 시도 → 차단
[ ] 사보타주 있는 밤 전환 응답 시간이 체감상 과도하게 느리지 않은지 (병렬화 확인, 대략 5~10초대 기대)
```

## TC-12. 회귀 확인 요약 (과거 수정된 버그들 — 재발 여부만 빠르게 스팟체크)

```
[ ] 대화 3회 제한이 대화창 재오픈해도 유지
[ ] 본인 상점 도난 인지 가능
[ ] 사보타주 연속 이틀 같은 장소 없음
[ ] 배드엔딩 배지 선노출 없음(로딩 화면 우선)
[ ] 오프닝 컷씬 텍스트 중복 없음
[ ] 씨앗 구매 시 골드 정상 차감
[ ] 걷기 애니메이션 방향 재재생 정상
```
