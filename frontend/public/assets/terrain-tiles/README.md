# Korean rural terrain tiles

대표 이미지의 낮은 탑다운 원근, 색상과 픽셀 밀도를 기준으로 제작한 지형 전용 타일 80개입니다. 건물, 캐릭터, 나무 같은 독립 오브젝트는 포함하지 않습니다.

## 규격

- 개별 타일: PNG, 128×128px
- 권장 게임 표시 크기: 64×64px 또는 128×128px
- 타일 수: 80개
- 원본 아틀라스: `atlases/`
- 전체 미리보기: `terrain-tiles-preview.png`
- 코드용 메타데이터: `terrain-tiles.json`

## 폴더

- `ground/`: 잔디, 흙, 밭, 진흙, 마른 풀
- `roads/`: 직선길, 굽은 길, 모서리, 교차로
- `rivers/`: 강물, 수로, 강변, 굽은 수로, 얕은 물
- `boundaries/`: 돌 제방, 논두렁, 밭 경계
- `transitions/`: 잔디와 흙·밭·논 사이 전환 지면

Phaser에서는 각 파일을 일반 이미지로 로드하거나, `atlases`의 4×4 시트를 4행 4열로 잘라 타일맵에 등록할 수 있습니다.
